The safe path

One source. Clean handoff.

The JSON backup path works across Docker, VPS, and remote installs. No database surgery required.

01 / SOURCE

Bring your backup

Upload a 9router dashboard JSON backup, or point at a legacy data.sqlite file.

02 / TRANSLATE

Choose an output

Generate an import-ready db.json, SQL file, direct database inject, or all three.

03 / VERIFY

Restart OmniRoute

Drop db.json into your data directory. OmniRoute picks it up on launch.
