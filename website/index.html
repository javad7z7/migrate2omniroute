The safe path

One command. A recoverable handoff.

The interactive server script backs up first, checks dependencies with permission, and keeps a complete audit trail on your machine.

01 / BACK UP

Snapshot 9router

Choose local SQLite, Docker, or dashboard JSON. The script validates the backup before touching OmniRoute.

02 / CHOOSE

Use or install OmniRoute

Already installed? It migrates only. Need it? It offers an isolated Docker install on a free port.

03 / VERIFY

Keep receipts

It backs up the OmniRoute database too, verifies the schema, injects only after confirmation, and saves a run log.
