## [1.0.0] - 2026-08-04

### Added
- Electron app for migrating 9router data to OmniRoute
- Auto-detect 9router and OmniRoute data paths
- Three output modes: db.json (auto-import), SQL file, direct inject
- Live migration log UI
- Support for connections, combos, API keys, custom models, settings
- Multi-platform builds: Windows (portable/zip), macOS (Intel/ARM zip), Linux (AppImage/deb)
